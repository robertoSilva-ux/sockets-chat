Sockets Chat — cliente
Av3 de Redes de Computadores · IFRS Rio Grande

O que é
-------
Cliente do chat da atividade. Precisa de Python 3.8 ou superior e destes dois
arquivos na MESMA pasta: cliente.py e protocolo.py.

Como usar
---------
1. Descompacte o pacote (vai criar a pasta cliente-av3).
2. Abra o terminal dentro dessa pasta.
3. Rode, com os dados do servidor que você vai usar:

     python cliente.py --nick seu_nick --servidor 192.168.0.10

   No Linux e no macOS, use python3.

     --nick      apelido de 3 a 16 caracteres (letras sem acento, números, _ ou -)
     --servidor  IP da máquina onde o servidor.py está rodando. Não use
                 127.0.0.1: isso aponta para a sua própria máquina.
     --porta     opcional; fixa a sua porta (por exemplo --porta 5001), útil
                 quando o firewall bloqueia a porta sorteada

   O IP correto é o que o servidor mostra ao subir, na linha marcada
   "rede local".

Comandos
--------
  /listar          quem está conectado (nick, IP e porta)
  /p2p <nick>      conversa direta (TCP) com essa pessoa
  /grupo <texto>   envia o texto para todos (UDP, pelo servidor)
  /sair            encerra a conversa aberta; fora dela, sai do chat

Problemas comuns
----------------
ModuleNotFoundError: No module named 'protocolo'
  Os dois arquivos não estão juntos, ou o terminal está em outra pasta.
  Entre na pasta cliente-av3 e rode de novo.

"servidor 127.0.0.1:9990 inacessível"
  Faltou o --servidor, ou o servidor não está no ar.

O /listar não mostra ninguém
  Confira o IP: precisa ser o da rede local, o mesmo que aparece na tela do
  servidor.

O /listar e o /grupo funcionam, mas o /p2p não abre a conversa
  O firewall da máquina que RECEBE a conversa pode estar bloqueando a porta de
  entrada. No Windows, a primeira execução abre um aviso: escolha "Permitir
  acesso" para redes privadas. Alternativa: rodar com --porta 5001 e liberar
  essa porta.
